# 利用規約（Cloveria Custom Hair Color Tool）

対象：Cloveria Custom Hair Color Tool と焼き込みツール（VCC で配るもの、GitHub に置いたソースコードと画面の素材を含む）。以下「本ツール」。

本ツールは、Atelier Cloveria の髪カラー商品（BOOTH で販売）と一緒に使うための道具です。本ツールを入れる・使う時点で、この規約に同意したものとみなします。

## 1. 使ってよいこと

- Atelier Cloveria の髪カラー商品を、購入者自身のアバターで使うために本ツールを使うこと
- 本ツールで作った色や、焼き込んだ画像を、購入者自身のアバターで使うこと（VRChat などへのアップロード、配信・収益化配信、スクリーンショット・動画を含む）
- 自分で使う範囲での本ツールの改変

## 2. 禁止すること

- 本ツールの再配布・販売・譲渡（改変したものを含む）
- 本ツールを、ほかの商品・アバター・ツールに組み込んで配ること
- 商品の確認（商品カード）を外す・回避する改変をして使うこと
- 焼き込みツールで作った画像と、光らせる機能が作る画像の再配布・譲渡
- 作者や第三者の権利を侵害する使い方、誹謗中傷につながる使い方

## 3. 他の権利者のもの

- 対応アバターの利用は、アバターの配布元の利用規約に従ってください
- ツール画面のフォント「Mochiy Pop One」は SIL Open Font License 1.1 で配布されています。このフォントには本規約ではなく OFL が適用されます（全文は同梱の OFL.txt）
- 本ツールは TexTransTool・NDMF（どちらも MIT ライセンス）を利用します。どちらも本ツールには含まれていません

- 本ツールは予告なく更新・配布停止する場合があります
- 不具合の連絡は BOOTH のショップのメッセージからお願いします。対応はできる範囲で行います
