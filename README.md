# Cloveria Custom Hair Color Tool

Atelier Cloveria の髪カラー商品で使う髪色ツールと焼き込みツールです。

**本ツールだけでは髪の色は変えられません。** [BOOTH](https://atelier-cloveria.booth.pm/) で購入した髪カラー商品と一緒に使ってください。

## 必要なもの

- Unity 2022.3（VRChat SDK のアバタープロジェクト）
- TexTransTool 1.0.x
- NDMF 1.7.0 以降
- Atelier Cloveria の髪カラー商品

## 入れ方

VCC（ALCOM）で入れます。追加用の URL と手順は、髪カラー商品に同梱の説明書をご確認ください。
